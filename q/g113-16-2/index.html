113年學測 克漏字 第16題

句型結構線索：跨句答對率 29%
答對率 29%：當年每 100 位考生，有 29 位答對。　⚠ 陷阱題，連高分群考生也常答錯

They 16 alarm clocks because adjustable alarms had been invented by the mid-19th century.

  1. (A)must be using
  2. (B)could have used
  3. (C)had hardly used
  4. (D)were mostly using

答案：(B)　could have used

題目編號：G113_16_2（已自動幫你填到回報表單裡）🚩 回報這題有問題

解析

could have + 過去分詞表示「過去本來可以（但實際上沒有）」，呼應下一句 But the new device was still relatively expensive and unreliable；must be using（現在的推測）、had hardly used（幾乎不曾用過）、were mostly using（當時大多在使用）都與下文矛盾。

深入解析

答對率 29%。

你可能會這樣想

讀到 because adjustable alarms had been invented by the mid-19th century（可調式鬧鐘在十九世紀中葉就發明了），你自然會推論「那他們就是在用鬧鐘啊」，於是挑了 were mostly using。這個推論在本句範圍內完全合理——問題出在下一句。

線索在下一句

But the new device was still relatively expensive and unreliable.（但這種新裝置當時仍然昂貴又不可靠）——這個 But 把前面的推論整個推翻：鬧鐘雖然已經存在，一般工人卻買不起、也信不過，所以實際上並沒有普遍使用。因此正解必須表達「本來可以用，但實際上沒有用」。這是典型的跨句題，只讀本句一定選錯。

文法依據

劍橋《English Grammar Today》在 could 條目指出：could have + 過去分詞用來談「過去的可能性」，例句 I could have been a lawyer.（我本來可以當律師的，言下之意是沒當成）。本句 They could have used alarm clocks 就是「他們本來可以用鬧鐘」，隱含「但沒有」。

干擾選項

must be using 是對「現在」的強烈推測，時態不合；had hardly used 是「幾乎不曾用過」，與 because 帶出的理由自相矛盾；were mostly using 則直接被下一句推翻。

常考字詞與句型

could have + p.p.（本來可以）、should have + p.p.（早該）、must have + p.p.（想必已經）、needn't have + p.p.（本來不必）。
