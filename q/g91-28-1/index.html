91年學測 克漏字 第28題

分詞／動狀詞線索：句內答對率 48%
答對率 48%：當年每 100 位考生，有 48 位答對。

Will the genetic copies of a human really have “one mind” as 28 in this story?

  1. (A)describes
  2. (B)described
  3. (C)describe
  4. (D)describing

答案：(B)　described

題目編號：G91_28_1（已自動幫你填到回報表單裡）🚩 回報這題有問題

解析

過去分詞 described，被動語意「如故事中所描述的那樣」（as described in this story，省略主詞的分詞構句，等同 as it is described）；describes／describe（限定動詞，不合這個省略結構）、describing（現在分詞，語意方向錯誤，應該是「被描述」不是「正在描述」）都不合。

深入解析

你可能會這樣想

as 後面只跟著一個字，你會覺得「少了東西」——連接詞後面不是應該接一個完整的子句嗎？於是很想補一個看起來完整的 describes 進去。答對率四成八、鑑別度只有 35，連高分群考生也大量失手，原因就在這裡：對「連接詞後面要接子句」這條規則越堅持的人，越容易把正確答案排掉。這一格考的正好是那條規則的例外——省略。

怎麼判斷

四個選項都是 describe 的不同形態，可見這一格考的是形態。先看空格前後：as ___ in this story，前面是 as，後面是介系詞片語，中間沒有主詞。沒有主詞就不可能填限定動詞，所以 describes 與 describe 先出局，它們都需要一個主詞來搭配。剩下 described 與 describing，靠方向來分：被描述的是「複製體擁有同一個心思」這個情況，它是被寫進故事裡的，不是它在描述別人，所以要用表被動的過去分詞 described。真正的結構是 as it is described in this story，as 後面把主詞 it 與 be 動詞 is 一起省掉了，只留下過去分詞。這種省略你其實見過，掛鉤是 While (he was) walking home（他走路回家的時候），連接詞後面的主詞與 be 動詞一起省略。把它還原出來讀一次就能自己驗算：Will the genetic copies of a human really have “one mind” as it is described in this story?（人類的基因複製體真的會像這個故事裡所描述的那樣，擁有「同一個心思」嗎？）。

干擾選項

describes、describe：限定動詞，需要主詞，而 as 後面沒有主詞可用。describing：現在分詞表主動，方向錯了——故事裡被描述的對象是這個情況，不是這個情況在描述什麼。

常考字詞與句型

as described（如所描述）、as mentioned above（如前所述）、as shown in（如……所示）、as expected（不出所料）、as required（依規定）、as follows（如下）。
