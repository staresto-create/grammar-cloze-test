83 年學測 克漏字 第19題

字彙選義線索：句內

The umbrella is now a very ordinary 19 .

  1. (A)subject
  2. (B)object
  3. (C)matter
  4. (D)element

答案：(B)　object

題目編號：G83_19_1（已自動幫你填到回報表單裡）🚩 回報這題有問題

解析

雨傘是具體的「物品」，object 指具體物品，符合語意。subject（主題/科目）、matter（事務）、element（元素）都不適合形容一個具體物品。

深入解析

本題大考中心未公布逐題答對率，以下不談數據，只談觀念。

你可能會這樣想

四個選項都是很常見的名詞，中文是「主題、物品、事情、元素」，如果沒把整句讀完，會覺得 matter 或 element 好像也能用。

怎麼判斷

四個選項都是名詞，可見這一格考的是語意。整句是 The umbrella is now a very ordinary ___.（雨傘現在是一件非常普通的……。）下一句是 Everybody uses it today.（今天每個人都在用它。）——講的是一件人人都會拿在手上的具體物品，所以填 object（物品、物體）。順便把這四個字分清楚：object 是具體的物品、物體（a strange object 一個奇怪的物體）；subject 是主題、科目（my favorite subject 我最喜歡的科目）；matter 是事情、事務，或指物質（a serious matter 一件嚴重的事）；element 是元素、要素（a key element 一個關鍵要素）。

誘答選項

subject（主題、科目）、matter（事情）、element（要素）：三個講的都是抽象的東西，而雨傘是拿得到、摸得著的實物。

常考字詞與句型

an object（物品、物體）、a subject（主題、科目）、a matter（事情、事務）、an element（要素、元素）、fold up（摺疊起來）、keep the rain off（擋住雨）。
