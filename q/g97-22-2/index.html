97 年學測 克漏字 第22題

字彙選義線索：句內答對率 42%
答對率 42%：當年每 100 位考生，有 42 位答對。

The woman did 22 without hesitation.

  1. (A)so
  2. (B)such
  3. (C)as
  4. (D)thus

答案：(A)　so

題目編號：G97_22_2（已自動幫你填到回報表單裡）🚩 回報這題有問題

解析

【句型】do so 固定用法，代替前面提到的動作（把寶石給他），表示「毫不猶豫地這麼做了」；such（不能這樣代替動作，通常修飾名詞）、as、thus（因此，這裡需要代動詞不是連接詞）都不合。

深入解析

你可能會這樣想

so 在你腦中幾乎等於「所以」，看到 The woman did ______ ，很難把 so 跟「做」聯想在一起。這一格答對率只有 42%，不到一半，卡住的原因幾乎都在這裡。其實 did so 的 so 不是「所以」，這一整組 do so 是替代用法（substitution），用來代替前面剛出現過的整個動作，避免重複（劍橋 English Grammar Today 的 substitution 條目）。

怎麼判斷

這件事你國中就學過最短的版本：Do you like it?—Yes, I do.（do 替代 like it）、When in Rome, do as the Romans do.（後面的 do 替代前面整串動作）。本題要替代的動作就藏在前一句：he asked her to give it to him（他要求她把寶石給他）。把 did so 還原回去驗算：The woman gave him the precious stone without hesitation.（那女子毫不猶豫地把寶石給了他。）讀起來完全通順，答案就定下來了。還有一個結構上的證據：did 是及物動詞的位置，後面卻看不到受詞——寶石到哪裡去了？因為它已經連同動作一起被 so 代掉了。這一格鑑別度高達 67，是全篇最高，分開的正是「有沒有動手把 did so 還原成前一句的動作」；沒有還原的人，讀到的只是一句意思模糊的「那女子就這麼做了」，接下來 The traveler left, rejoicing 為什麼要 rejoicing，也跟著糊掉。103 年第 29 題 →同樣考 do so，那一題把它藏在 before they have the time to do so 裡面，兩題可以擺在一起練。

誘答選項

such：是修飾名詞用的，像 such a thing、such generosity，不能單獨接在 did 後面代替動作。as：要接子句才成立，例如 She did as he asked.（她照他要求的做了），但空格後面是句號，沒有子句。thus（因此）：是轉承語，功能是標示前後句的邏輯關係，它不能當動詞的受詞，did thus 不是現代英文的用法。

常考字詞與句型

do so（這麼做，替代前面提過的動作）、without hesitation（毫不猶豫地）、such a thing（這樣的事）、do as somebody asks（照某人要求的去做）、ask somebody to do something（要求某人做某事）、leave rejoicing（心滿意足地離開）。
